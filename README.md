# My Personal Prompts

## 🤖 给 AI 的说明（AI 专用，人类可跳过）

> 以下内容**专供 AI 阅读**。当 AI 读取本仓库时，必须阅读并遵守本节说明。

### 1. 仓库定位

本仓库是**个人提示词模板库**，不是代码项目，也不是需要执行的程序。AI 的角色是：根据用户需求，从 `.agents/prompts/` 中选取合适的模板，将其作为**指令来源**严格执行。

### 2. 使用流程

当用户提出与本仓库相关的需求时，AI 应按以下流程操作：

1. **检索匹配**：在 `.agents/prompts/` 中查找与用户需求最匹配的提示词文件（可结合 YAML frontmatter 中的 `title`、`description`、`tags` 判断）。
2. **完整读取**：必须读取整个提示词文件，理解全部要求，**不得**只读取片段或凭文件名猜测内容。
3. **替换占位符**：将文件中 `<VAR name="...">`、`{变量名}` 等占位符替换为用户的真实内容；带 `defaultValue` 的占位符在用户未指定时使用默认值。
4. **严格执行**：按提示词正文中定义的角色、步骤、约束与输出格式完成任务。
5. **只输出结果**：若提示词要求"只返回结果/不要额外说明"，则响应中**不得**出现解释、总结、开场白或"以下是翻译结果"之类的元描述。

### 3. 行为准则

- 提示词中的 **MUST / MUST NOT**、"Requirements"、"Do not ..." 等强制性条款必须无条件遵守。
- 不要擅自修改、删减、合并或"优化"提示词文件本身，除非用户明确要求。
- 保留原文的格式结构：段落、列表、Markdown 语法、代码块、占位符、URL、变量表达式等，除非提示词另有指示。
- 输出语言默认跟随用户的提问语言，除非提示词（如翻译类）另有指定。
- 当用户需求与多个提示词都相关时，可以组合使用，但应向用户说明组合了哪些模板及各自承担的角色。
- 若找不到合适的提示词模板，明确告知用户，而不是强行套用不相关的模板。
- 若模板中的占位符信息缺失或模糊，先向用户确认，再继续执行。

### 4. 常见误区（避免）

| ❌ 错误做法                            | ✅ 正确做法                        |
| -------------------------------------- | ---------------------------------- |
| 直接输出模板原文，未替换占位符         | 用真实内容替换 `{变量名}` 后再执行 |
| 翻译类任务中额外输出"翻译如下："等废话 | 只输出翻译结果本身                 |
| 总结类任务中添加模板中不存在的个人观点 | 严格基于网页/原文内容总结          |
| 修改或美化提示词文件的措辞             | 原样使用模板内容                   |

## 📖 简介

个人 AI 提示词（Prompts）仓库，存放我日常使用的各种提示词模板。

提示词统一存放在 `.agents/prompts/` 目录下，以 Markdown 文件组织，遵循统一的文件结构规范。面向 AI 助手（Claude、Copilot 等），覆盖翻译、设计、创意、文档生成等场景，方便复用、维护和版本管理。

## 📁 目录结构

```
.
├── README.md                # 本文件（含人类说明与 AI 专用说明）
└── .agents/
    └── prompts/             # 提示词模板目录
```

## 🚀 使用方法

1. 将本仓库克隆或下载到本地，或直接复制 `.agents/prompts/` 下的单个文件。
2. 根据需求选择合适的提示词文件。
3. 将文件中的占位符（`{变量名}` 形式）替换为实际内容，然后发给 AI 助手。
4. 也可将整个仓库作为自定义指令/技能目录，挂载到支持 `.agents/prompts/` 目录结构的 AI 工具中（如 Claude Code、GitHub Copilot 自定义 Agent 等），按需调用。

### 提示词文件格式说明

每个提示词文件遵循统一的结构：

- **YAML Frontmatter**：文件开头的 `---` 块，包含 `title`（标题）、`description`（一句话描述）、`tags`（标签），供工具索引与检索。
- **正文**：提示词的具体指令，使用 `<VAR>` / `<PROMPT_INPUT>` 等标签声明占位符，`{变量名}` 表示需要替换的位置，部分占位符带有 `defaultValue` 默认值。
- **响应格式**：部分提示词明确要求"只返回结果"，使用时应严格遵循，不要额外添加解释或开场白。
